# 斗地主 · 三人局

基于 **Tauri 2、Vue 3、TypeScript 与 Rust** 的独立 Windows 桌面斗地主游戏。支持一名玩家对两名电脑，以及同一局域网内的三人对局；无需账号或在线服务。

扑克牌、牌桌和应用图标在本项目内绘制，音效由 Web Audio 合成。项目不依赖其他游戏的安装目录、源码或素材。

## 开发运行

环境要求：

- Node.js 20 LTS 或更新版本，以及 npm。
- Rust stable，Windows 使用 MSVC 工具链。
- Visual Studio 2022 Build Tools 的“使用 C++ 的桌面开发”和 Windows SDK。
- Microsoft Edge WebView2 Runtime。

在本项目目录执行：

```powershell
npm install
npm run tauri dev
```

`npm run tauri dev` 会同时启动 Vite 和 Rust 游戏后端。仅执行 `npm run dev` 时，网页可加载界面，但不具备原生游戏服务；请在 Tauri 桌面窗口中对局。

开发服务器使用 `127.0.0.1:1430`，与其他独立项目的开发端口分开。

生成 Windows 程序和 NSIS 安装包：

```powershell
npm run tauri build
```

输出目录：

- 程序：`src-tauri/target/release/doudizhu2026.exe`。
- 安装包：`src-tauri/target/release/bundle/nsis/`。

首次安装和构建需要下载 npm、Cargo 依赖及打包工具。本次源码交付未安装依赖，也未执行构建、类型检查、测试或启动验证。

## 基本操作

- **开始对局**：初始为等待状态，点击开始后才洗牌、发牌和计时。
- **暂停 / 继续**：暂停时冻结当前操作的剩余时间，同时停止电脑与托管行动；继续后沿用原来的余额。
- **选牌**：点击单张牌切换选中，按住并拖动可批量选择；再次调整后点击出牌。
- **整理**：切换手牌的点数排列方向，不改变真实持牌内容。
- **提示**：根据自己的手牌和公开信息给出建议，选中建议牌后仍需自己确认；也可能建议不出。
- **不出**：仅跟牌时可用，领出方必须出牌。
- **托管**：电脑代为叫牌、跟牌或领出，可随时取消。托管与电脑行动共用规则校验。
- **快捷键**：非输入框和弹窗状态下，Enter 确认已选手牌，Space 在允许时不出，Esc 清除选牌。聚焦按钮时保留按钮自身的键盘操作。
- **新对局**：单机下按当前设置重新准备牌桌，累计成绩重新开始；普通“再来一局”保留同桌累计积分。

可以在设置中修改昵称、地主规则、底分、操作时限和音效偏好。时限范围为 0～120 秒，0 表示不限时。设置保存在应用配置目录的 `settings.json`；Windows 通常为 `%APPDATA%\com.kikyoshaw.doudizhu\`。

倒计时结束时，竞叫默认不叫/不抢；跟牌默认不出；领出则自动打出一张合法牌，避免卡住对局。牌局最终时序由 Rust 单调时钟裁定。

## 玩法与牌型

使用一副 54 张牌，无癞子。每人 17 张，保留 3 张底牌；地主确定后取得底牌，以 20 张手牌先出，另一方两名玩家共同为农民。

### 叫分

随机一名玩家开始，轮流选择不叫或 1、2、3 分，只能叫高于当前最高值的分数。叫 3 分立即确定地主；否则三次决定后由最高叫分者成为地主。三人都不叫时，本轮不结算，点击重新发牌（联机需重新准备后由房主发起）。

### 叫抢

随机首叫，按顺序决定叫地主或不叫。第一名叫地主的玩家成为首叫者，其余两名玩家依次选择抢或不抢。若发生抢地主，首叫者再获得一次抢回机会；最后一次成功叫/抢者成为地主，每次成功抢地主将倍数翻倍。若三人均不叫，则重新准备发牌。

### 支持牌型

| 牌型 | 规则 |
| --- | --- |
| 单张、对子、三张 | 相同点数的 1、2、3 张牌 |
| 三带一、三带二 | 一个三张搭配不同点数的单张或对子 |
| 顺子 | 至少 5 个连续点数，每点数一张 |
| 连对 | 至少 3 个连续对子 |
| 三顺 / 裸飞机 | 至少 2 个连续三张 |
| 飞机带单 | 连续三张主体搭配同等组数的单牌；单翅可出现对子，但不能用四张同点数牌作为翅膀 |
| 飞机带对 | 连续三张主体搭配同等组数的不同点数对子 |
| 四带二张 | 四张同点数搭配两张牌，两张可以组成对子 |
| 四带两对 | 四张同点数搭配两个不同点数的对子 |
| 炸弹 | 四张同点数牌 |
| 王炸 | 大王与小王 |

所有连续主体均只能使用 3 到 A，不包含 2 和大小王。飞机翅膀不能使用主体点数；三张主体不能把同点数第四张放进翅膀。

普通牌只比较相同牌型、张数和连续长度，主体点数更大才能压过上一手。炸弹可压过普通牌，炸弹之间按点数比较，王炸最大。

存在多种合法解释的飞机会由规则引擎枚举解释：跟牌时选择能够匹配并压制上一手的解释；领出时采用固定顺序，优先更长的连续三张主体。实际解释随出牌结果保存，客户端不自行重新判定。

两名玩家连续不出后，上一手出牌者重新领出，不受上一手牌型约束。任意一名玩家出完手牌后立即结束本局；地主单独胜负，农民共享胜负。

## 倍数与积分

每局单位分为：

```text
单位分 = 底分 × 叫分或抢地主倍数 × 炸弹倍数 × 春天倍数
```

- 叫分模式以最终叫分为基础倍数；叫抢模式初始一倍，每次抢地主翻倍。
- 每次合法炸弹或王炸均再翻倍。
- 地主获胜且两名农民都未成功出过牌，计“春天”，再翻倍。
- 农民获胜且地主只成功出过一手，计“反春”，再翻倍。
- 地主获胜获得两倍单位分，两名农民各扣一倍；农民胜则相反，三人总分为零。

积分仅为同一桌连续对局的游戏成绩，不涉及充值、支付或实物奖励。结算仅执行一次；新单机对局或房间人员变化会重新开始累计成绩。累计分不跨应用重启保存。

## 电脑与提示

电脑使用基于牌型候选和手牌分组的启发式策略，考虑减少手数、保留炸弹/王、阻止对手出完以及农民同队配合。

电脑、托管与提示只能读取该玩家自己的手牌、对手剩余张数、地主身份和公开出牌，不读取其他玩家的私有手牌。它不是训练模型或专业求解器，策略强度以休闲对局为目标。

## 三人局域网

1. 三台电脑处于同一局域网，启动相同版本的客户端。也可以在一台电脑上运行三个实例，用 `127.0.0.1` 加入。
2. 房主选择创建房间，设置昵称、地主规则、底分、步时及端口，默认端口 `9528`。
3. 其余两位输入房主的局域网 IP 和相同端口加入。房主可用 Windows `ipconfig` 查询本机 IPv4 地址；`0.0.0.0` 表示监听地址，其他电脑应填写实际 IPv4 地址。
4. 如防火墙提示，请允许程序在当前专用网络通信。
5. 三位均点击准备后，由房主点击开始。每局结束或全不叫后重新准备，再由房主发起下一局。

联机为三名真人，不自动补电脑。开局、暂停和继续由房主控制；访客可管理自己的准备和托管。

房主统一校验持牌、回合与牌型。每名客户端只获得自己的手牌和对手剩余数量；地主确定前不公开三张底牌。

玩家在对局中断线时，中止本局且不结算积分，清除准备状态；房间保留另一名玩家的连接，继续等待替补。成员变化后累计积分归零，三人重新准备。房主断线后访客显示断线原因，可离开房间返回单机。首版不自动重连，不恢复中断的半局。

网络协议使用独立产品标识、版本号、四字节大端长度前缀和 JSON，单帧最多 64 KiB，具有握手、心跳、有界队列和会话代次保护。该房间功能面向局域网，不提供公网匹配或账号服务。

## 工程结构

```text
src/
  App.vue                     牌桌与对话框流程
  components/                 扑克牌、拖选手牌、座位和公开出牌区
  composables/useGame.ts       IPC、快照、等待状态、计时与提示
  composables/useSound.ts      合成音效及资源清理
  types.ts                    前后端数据契约
src-tauri/src/
  lib.rs                      桌面入口与命令
  game/cards.rs               54 张唯一牌、洗牌和排序
  game/combo.rs               牌型识别、解释、比较和候选
  game/ai.rs                  公开信息策略、叫牌与提示
  game/mod.rs                 发牌、竞叫、出牌和积分
  session.rs                  阶段、计时、座位视图、托管和版本
  network.rs                  三人 TCP 房间及连接清理
  storage.rs                  设置持久化
```

Rust 内部完整牌局不会直接序列化。所有 UI 和网络状态均通过按座位生成的快照传递；操作携带会话、局号和回合令牌，后台行动在提交前复核，暂停、重开或断线后不接受旧任务结果。

## 手动验收建议

- 检查发牌后 54 张不重不漏，三人各 17 张；地主确定后为 20/17/17，底牌此前不公开。
- 覆盖叫分加价、3 分立即结束、叫抢顺序、首叫者抢回及全不叫。
- 覆盖表格中的全部牌型，特别是不能带 2/王的连续主体、飞机主体与翅膀、四带二和不同长度不可互压。
- 检查选中重复牌或非本人手牌会被拒绝，领出不能不出，两次过牌后正确恢复领出。
- 检查点击/拖选/整理/提示/托管，过期提示不改变新手牌。
- 启动时不发牌计时；暂停后余额不变，继续不补满；旧电脑任务不会在暂停或新局后出牌。
- 检查超时竞叫、跟牌和领出；0 秒不限时仍可正常托管与暂停。
- 验证地主和农民结算、春天与反春、炸弹翻倍，以及累计积分总和为零。
- 三个客户端验证准备、地主确定前的底牌隐藏、只接收自己的手牌、房主阶段控制、断线中止及替补加入。
